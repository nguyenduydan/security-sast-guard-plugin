# Security SAST Guard — Release Notes v0.0.1

**Release Date:** 03/08/2026  
**Version:** `v0.0.1`  
**Classification:** Official Initial Release  

### Executive Summary
Phiên bản phát hành chính thức đầu tiên `v0.0.1` của Security SAST Guard Plugin cho Antigravity & Gemini CLI. Tích hợp trọn bộ 53 quy tắc SAST (OWASP/CWE/NIST), quy trình kiểm soát chất lượng mã nguồn Pre-Commit và hệ thống CI/CD tự động hóa Release Please.

### What's Changed

#### 🚀 Features & SAST Security Rules
* **53 OWASP/CWE/NIST Security Rules:** Added full static analysis rule definitions for OWASP API 2023, Web 2021, CWE Top 25, and NIST 800-53.
* **Modern Pre-Commit Pipeline:** Integrated 14-step hooks with Ruff linter/formatter, Mypy strict type checking, Pytest, and Detect-Secrets.
* **Silent AI Skill Directives:** Refactored SAST Guard skills to execute background Python scripts smoothly without chat UI clutter.

#### ⚡ Architecture & CI/CD
* **Python 3.12+ Standard:** Modernized project setup in `pyproject.toml` and `.pre-commit-config.yaml`.
* **CI Quality Gate:** Integrated `ci.yml` and `release.yml` with 10.0/10 Pylint score.
* **Release Please Automation:** Full release-please-action integration with custom changelog sections.
