# Security SAST Guard — Release Notes v1.1.0-rc3

**Release Date:** 03/08/2026  
**Version:** `v1.1.0-rc3`  
**Classification:** Pre-release / Minor Candidate  

### Executive Summary
Phiên bản `v1.1.0-rc3` mang đến bước tiến lớn về khả năng kiểm tra an ninh tĩnh (SAST), quy trình kiểm soát chất lượng mã nguồn tự động và tự động hóa xuất bản GitHub Release.

### New Features & Improvements
* **53 SAST Security Rules:** Mở rộng khả năng phát hiện lỗ hổng API (BOLA, SSRF, Mass Assignment, Broken Auth) và Web vulnerabilities.
* **Modern Pre-Commit Pipeline:** Tích hợp Ruff (linter/formatter), Mypy (strict type checking), Pytest và Detect-Secrets.
* **Automated GitHub Release:** Tự động tạo bài Release đầy đủ mô tả trên GitHub khi push Git Tag dạng `v*`.
* **Silent AI Skill Execution:** Tái cấu trúc các skill của SAST Guard để chạy ẩn ngầm các lệnh Python, tối ưu token và giữ trải nghiệm chat sạch sẽ.
* **Pylint Quality Score 10.0/10:** Khắc phục toàn bộ các cảnh báo linter và hoàn thiện CI workflow.

### Upgrade Guide
```bash
git pull origin main
git checkout tags/v1.1.0-rc3
pre-commit install
```
