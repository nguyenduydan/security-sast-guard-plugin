SECURITY SAST GUARD v2.0.0 CORE

13 Symbiotic Security Modules

A fully integrated defense ecosystem. 13 specialized modules working in zero-conflict symbiosis to protect your shell, verify code, and govern security decisions.

MODULE 01

Firewall Normalizer

10-Stage Anti-Bypass Deobfuscator. Strips carets (c^m^d), backticks, hex escapes (\x52), Base64, char codes, and expands aliases.

Domain: Command Defense 500ms Stage Timeout
MODULE 02

Capability Classifier

Categorizes command tokens into 7 distinct capability groups: NETWORK, FILE_READ, FILE_WRITE, PROCESS_EXEC, PRIVILEGE_CHANGE, PERSISTENCE, DATA_TRANSFER.

Domain: Behavioral Classification 7 Groups
MODULE 03

Intent Classifier

Evaluates capabilities into high-level intent labels (EXFILTRATION, DESTRUCTIVE, PERSISTENCE, PRIVILEGE_ESCALATION) with computed confidence scores.

Domain: Semantic Reasoning Confidence Scoring
MODULE 04

Attack Chain Analyzer

Detects dangerous multi-command combinations (e.g. Download + Execute, Policy Bypass + Run) that appear benign in isolation but deadly in chain.

Domain: Multi-Step Attack Chain Chain Threat Guard
MODULE 05

Security Decision Engine

Formal 4-State Machine (TRUE_POSITIVE, FALSE_POSITIVE, CONFIRM_REQUIRED, NOT_ENOUGH_CONTEXT) with Policy Overrides and multi-weight risk formula.

Domain: Risk Processing 4-State Machine
MODULE 06

Fingerprint Tracker

Computes location-independent SHA-256 semantic fingerprints. Tracks vulnerability baselines across refactors with automatic tamper verification.

Domain: Baseline Tracking Line-Independent
MODULE 07

Rule Integrity Validator

Verifies SHA-256 checksums of custom SAST rules to block unauthorized rule tampering. Contains heuristic ReDoS regex safety checks.

Domain: Rule Protection ReDoS Guard
MODULE 08

Append-Only Audit Log

Cryptographic append-only JSONL audit log (.sast/firewall_audit.jsonl) with cryptographic hash chain integrity verification.

Domain: Audit Governance SHA-256 Hash Chain
MODULE 09

Evidence Engine

Constructs Evidence Graphs connecting sources, propagation paths, sanitizers, and sinks. Extracts program slices for concise token-saving analysis.

Domain: Dataflow & Slicing Program Slicer
MODULE 10

Bounded Verification Harness

Enforces strict execution constraints on verification loops: Max 5 iterations, 10 tool calls, 30s execution, 1MB output, 20 files read, 128MB RAM.

Domain: Resource Boundary Max 5 Iterations / 30s
MODULE 11

Adaptive Knowledge Base

Trusted Sanitizer Registry with Human/Policy Approval Gate. Prevents AI agents from auto-approving unverified sanitizers without human signature.

Domain: Sanitizer Governance Human Approval Gate
MODULE 12

Standards Mapper & Metrics

Maps rule triggers to OWASP Top 10, CWE Top 25, and NIST 800-53 controls while computing real-time Precision, Recall, F1, FPR, and FNR quality metrics.

Domain: Compliance & Metrics Precision & F1 Engine
MODULE 13

Framework Semantics Engine

Extensible Strategy Pattern handling ASP.NET WebForms server controls (<asp:TextBox>, runat="server") and multi-language framework semantics.

Domain: Framework Semantics ASP.NET & Strategy Pattern

Slash commands integrated directly into AI assistant sessions for fast security audits and rule management:

🛡️ /sast-audit <file|codebase|api|web> <path>
Runs OWASP/CWE static audit. Outputs Pure ANSI TUI, Markdown, and SARIF 2.1.0 reports.
🧬 /sast-rules [sync <dir>|add <file>]
Parses and syncs custom Markdown security rules with SHA-256 integrity verification.

Displays version, project ID, tech stack, operation mode, and active rules count.
🚀 /sast-init
Creates project-local .sast/profile.json security profile.

Switches operation mode (strict: full enforcement, draft: auto-allow low/medium).
🎚️ /sast-audit-level [lite|full|ultra]
Sets active audit strictness level for project or global workspace.
