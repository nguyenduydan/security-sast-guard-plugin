Install Plugin

PowerShell Core 7+
// Downloads release ZIP, extracts, and configures Antigravity CLI plugin
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/nguyenduydan/security-sast-guard-plugin/main/install.ps1" -OutFile "install.ps1"; .\install.ps1
// Run from the parent plugins directory to avoid Windows file-lock issues
cd $HOME\.gemini\config\plugins; .\security-sast-guard\update.ps1
// Safely uninstalls plugin and restores original environment
cd $HOME\.gemini\config\plugins\security-sast-guard; .\remove.ps1

Plugin Usage & Controls

Execute security audits, initialize project profiles, launch Stdio MCP Server, and test firewall rules in real-time.

AI Chat Slash Commands

Antigravity Chat & Gemini CLI
Interactive

Slash commands integrated directly into AI assistant sessions for fast security audits and rule management:

🛡️ /sast-audit <file|codebase|api|web> <path>
Runs OWASP/CWE static audit. Outputs Markdown and JSON reports.
🧬 /sast-rules [sync <dir>|add <file>]
Parses and syncs custom Markdown security rules into active ruleset.
📊 /sast-status
Displays version, project ID, tech stack, operation mode, and active rules count.
🚀 /sast-init
Creates project-local .sast/profile.json security profile.
🎛️ /sast-mode [strict|draft]
Switches operation mode (strict: full enforcement, draft: auto-allow low/medium).
🎚️ /sast-audit-level [lite|full|ultra]
Sets active audit strictness level for project or global workspace.
